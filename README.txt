AUREA SORIANO-VARGAS · ACADEMIC WEBSITE
======================================

CONTENTS
- index.html: complete responsive academic website with embedded portrait, CSS and JavaScript.
- Aurea_Soriano_Vargas_CV.pdf: downloadable academic CV linked from the homepage.
- portrait.webp: web-optimized copy of the portrait embedded in index.html.
- academic_data.json: structured source data for future edits.

HOW TO PREVIEW
Open index.html in any modern web browser.

HOW TO PUBLISH
Upload index.html and Aurea_Soriano_Vargas_CV.pdf into the same folder of a web host (e.g. Netlify, GitHub Pages). The portrait, styles, search, filtering, and dark-mode code are inside the HTML. No build steps or dependencies are required. Online fonts are optional and fall back gracefully when offline.

HOW TO UPDATE
- Edit headline, email, research highlights, or layout text in index.html.
- Research records are embedded in the JSON script tag with id=cv-data.
- academic_data.json is supplied as an editable reference. Updating that file alone does NOT update the website: replace the embedded JSON with its contents after editing.
- Update the linked CV PDF when new CV versions are available.

SOURCE
Built from the LaTeX sections and publications.bib inside CV_AureaSoriano.zip as provided on October 20, 2026. Research output totals include conference contributions identified as accepted with forthcoming proceedings. The publicly displayed website intentionally omits the mobile phone number for privacy; the source CV remains unchanged.
